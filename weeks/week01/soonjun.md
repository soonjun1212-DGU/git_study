## 🎯 미션

**1. 뭘 했나요?** (한 줄)
test.log 파일을 생성해 .gitignore에 의해 실제로 무시하는지 확인하기 위해 add 명령어를 실행했다. 

**2. 어떤 명령어를 쳤나요?** (터미널에 친 거 그대로 복붙!)
```bash
git switch -c "week01/soonjun"
git add test.log
rm test.log
```

**3. 해보니까 어땠나요?**
- `.gitignore`에 적으니까 `git status`에서 test.log가 나타나지 않았다
- add를 하니까 진짜로 추가하고 싶으면 '-f'를 사용하라고 했다

## 💡 새로 안 것


**몰랐는데 이번에 알게 된 것** (1~3줄, 아는 건 안 써도 돼요)
- .gitignore을 통해 특정 파일을 깃이 제외할 수 있다는것을 알게 되었다. 
- 깃은 로컬 데이터 베이스를 이용하기 때문에 네트워크에 연결되어있지 않아도 작동가능하다
- 깃은 체크섬(해시)을 구해 데이터를 관리한다

**궁금하거나 헷갈린 것** (하나면 충분, 화요일에 같이 이야기해요)

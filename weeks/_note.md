## 🎯 미션

**1. 뭘 했나요?** (한 줄)
- 예) `.gitignore` 파일을 만들어서 `desktop.ini`가 안 올라가게 막았다

**2. 어떤 명령어를 쳤나요?** (터미널에 친 거 그대로 복붙!)
```bash
예) git status
예) git add .gitignore
```

**3. 해보니까 어땠나요?**
- 예) `.gitignore`에 적으니까 `git status`에서 `desktop.ini`가 사라졌다

## 💡 새로 안 것

**몰랐는데 이번에 알게 된 것** (1~3줄, 아는 건 안 써도 돼요)
- 예) `git add` 해야 커밋에 들어간다. 파일 저장만으로는 안 된다

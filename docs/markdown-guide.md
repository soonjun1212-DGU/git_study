## 🔤 자주 쓰는 문법

| 이렇게 쓰면 | 이렇게 보여요 |
|---|---|
| `# 제목` | 큰 제목 (`#` 뒤 띄어쓰기 필수!) |
| `## 소제목` | 섹션 제목 |
| `**굵게**` | **굵게** |
| `` `git status` `` | `git status` |
| `- 항목` | • 목록 |
| `1. 항목` | 1. 번호 목록 |
| `> 인용` | 인용 박스 |
| `[글자](주소)` | 링크 |
| `- [ ] 할 일` | 체크박스 |

명령어, 파일 이름, 브랜치 이름은 백틱(`` ` ``)으로 감싸요. 키보드 `~` 키에 있어요.
